# 우정 사진관 카메라

금일초 친구사랑 어울림 축제의 '친구사랑 우정 사진관' 부스에서 아이패드를 카메라로 쓰려고 만든 페이지입니다.

주소: https://eunhorang.github.io/friendship-cam/

## 왜 따로 있나요

맥은 아이패드 카메라를 맥 카메라로 받을 수 없습니다. 연속성 카메라(웹캠)는 아이폰만 됩니다. 대신 케이블로 연결한 아이패드의 화면은 받을 수 있어서(QuickTime이 아이패드 화면을 녹화할 때 쓰는 기능) 이 페이지가 아이패드 화면 가운데에 카메라 영상만 크게 띄우고 맥의 사진관이 그 부분을 잘라 카메라로 씁니다.

이 페이지는 영상을 어디에도 보내지 않으며 사진은 케이블을 따라 맥으로만 갑니다.

## 쓰는 법

1. 아이패드 사파리에서 위 주소를 열고 공유 단추의 '홈 화면에 추가'로 홈 화면에 아이콘을 만듭니다('웹 앱으로 열기'가 보이면 켜 둡니다). 한 번만 하면 되고 그다음부터는 인터넷이 없어도 열립니다.
2. 홈 화면의 '사진관 카메라'로 엽니다. 사파리 안에서는 카메라를 켤 수 없게 해 두었습니다. 사파리 전체 화면의 닫기 단추(X)가 사라지지 않고 사진 왼쪽 위에 찍히기 때문입니다.
3. 아이패드를 가로로 세우고 맥스튜디오에 USB-C 케이블로 연결합니다. 처음 연결하면 아이패드에서 '신뢰'를 누릅니다.
4. '카메라 켜기'를 누르고 카메라 사용을 허용합니다. 맥의 사진관 화면에 아이패드 카메라가 보이면 준비가 끝난 것입니다.

축제 중에는 이렇게 해 두면 좋습니다.

- 알림이 화면에 뜨면 사진관에도 비치니 제어 센터에서 방해 금지 모드를 켜 둡니다.
- 설정 > 디스플레이 및 밝기 > 자동 잠금을 '안 함'으로 둡니다. 페이지도 화면이 꺼지지 않게 막지만 저전력 모드에서는 막지 못할 수 있습니다.
- 기본은 뒤 카메라이고 친구들이 아이패드 화면을 보며 서야 한다면 아래 띠의 '앞 카메라로'를 눌러 바꿉니다.

## 사진관이 이 화면을 알아보는 법

화면 위쪽 검은 띠 오른쪽의 흰 네모 열한 칸이 '사진관 카메라가 제자리에 떠 있다'는 표시입니다. 맥의 사진관은 이 표시를 찾았을 때만 화면을 받아 쓰므로 홈 화면이나 다른 앱 화면은 사진관에 나가지 않습니다. 표시는 홈 화면 웹 앱으로 열었을 때만 켜집니다.

아이패드는 웹 앱에서도 왼쪽 위에 X 단추를 늘 띄워 둡니다(iPad mini 6에서 위에서 약 78pt). 그래서 카메라 칸을 가운데보다 아래로 내려 위쪽 띠가 X 단추와 시계·배터리 줄을 덮게 하고 아래 띠에는 홈 막대가 들어가게 합니다. 맥은 카메라 칸만 잘라 가므로 이 단추와 줄은 사진에 나가지 않습니다.

자리 약속(표시 2판, 사진관 `tools/ipad-camera.swift`와 같아야 합니다): 가로 W, 세로 H인 화면에서

- 카메라 칸: 가로 W, 높이 h = W×9/16. 남는 높이 S = H − h 가운데 위쪽 띠가 t = S × k / 16 (k는 0~15)
- 표시: 위쪽 띠의 y = 0.045W 줄에 한 변 0.02W인 칸 열한 개, i번째 칸 가운데 x = W × (0.675 + 0.03i)
- 앞 여섯 칸은 늘 흰칸·빈칸·흰칸·흰칸·빈칸·흰칸, 다음 네 칸은 k(큰 자리부터), 마지막 칸은 흰칸 개수를 홀수로 맞춥니다.

k를 표시에 담아 두었기 때문에 카메라 칸 위치를 바꿀 때는 이 페이지만 고치면 됩니다.
